# DBMS-Ecommerce-Platform
A Java-based DBMS e-commerce platform that connects users and companies through smart product search, recommendations, cart, wishlist, feedback and analytics features.

##  Overview

Company Search & Product Match Platform is a Java-based DBMS project designed to create an interactive e-commerce environment where users can search products, explore company offerings, manage their shopping activities, and provide feedback.

The system connects two major portals:

- User Portal
- Company Portal

Users can discover products, add items to wishlist/cart, view product details, submit reviews, and maintain search history.

Companies can manage products and analyze customer interactions through product analytics.

#  Features
##  User Portal

### Authentication
- User registration
- Secure login system
- Password reset functionality


### Product Search
- Search products by keywords
- Filter products by category
- View company details
- Explore product descriptions


### Shopping Features

- Add products to wishlist
- Add products to cart
- Remove cart items
- Checkout simulation

### Product Interaction

- View product details
- Submit ratings and reviews
- View customer feedback
- View related products


### Search History

- Stores user searches
- Allows quick access to previous searches
